🎙 녹음 앱 + Whisper STT + Claude → 회의록 자동화
회의를 녹음하고, Whisper로 텍스트 변환 후, Claude가 구조화된 회의록으로 정리합니다. Obsidian에 자동 저장까지 연결됩니다.
1스마트폰으로 회의 녹음 (클로바노트, 삼성 음성 녹음 등)
2Whisper 또는 Ollama로 음성 → 텍스트 변환
3회의록 자동 완성 시스템 프롬프트로 Claude 요약
4Obsidian 노트로 자동 저장 및 태그 분류
📰 뉴스/공시 + Claude → AI 투자 리서치
관심 종목의 뉴스·공시·재무 정보를 Claude에 붙여넣어 체계적인 리서치 보고서를 생성합니다. /cs 명령으로 매일 추적 관찰합니다.
1투자 리서치 시스템 프롬프트 설정 (1회)
2/분석 [종목명] 으로 기본 리서치 시작
3/뉴스 로 최근 이슈 요약 및 영향 분석
4/cs 로 매일 추적 관찰 및 감정 점검
Claude + Notion → 지식 관리 시스템
Claude로 학습한 내용을 구조화하고, Notion에 체계적으로 저장합니다. 나중에 Claude에 노션 내용을 다시 붙여넣어 활용합니다.
1학습하거나 읽은 내용을 Claude에 붙여넣기
2"이 내용을 Notion 데이터베이스 형식으로 정리해줘" 요청
3Claude가 표, 태그, 요약, 액션아이템 분리해서 정리
4Notion에 복붙하여 지식 베이스 누적
Excel/CSV + Claude + Python → 데이터 자동화
반복적인 Excel 보고서 작업을 Python 스크립트로 자동화합니다. Claude가 코드를 작성해주니 프로그래밍 경험이 없어도 가능합니다.
1Excel 데이터와 원하는 보고서 형식 설명
2Claude에게 Python 스크립트 작성 요청
3스크립트 실행 → 보고서 자동 생성
4매월 데이터만 바꿔서 반복 실행
