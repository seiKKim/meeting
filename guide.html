음성 녹음 → 회의록
자동 완성 시스템

녹음 파일을 폴더에 넣고 더블클릭 한 번으로 회의록을 완성합니다. Whisper로 받아쓰고, Ollama로 요약하고, Obsidian에 저장합니다. 모든 처리가 이 PC에서만 이루어집니다.

전체 파이프라인 흐름
🎙️ 음성 입력 → 📝 Whisper STT → 🤖 Ollama 요약 → 📓 Obsidian 저장
📋
STEP 00 · 시작 전 확인
환경 확인
왜 필요한가
설치 전에 Python, Ollama, Obsidian이 모두 준비되어야 합니다. 한 가지라도 없으면 파이프라인이 동작하지 않습니다.

모두 충족. Python 3.14, Ollama 0.30.6, Obsidian, RTX A2000 GPU — 바로 사용 가능합니다.

STEP 01~05 · 처음 한 번만
설치
목표
5단계를 순서대로 따라하면 더블클릭 실행 환경이 완성됩니다. 이미 설치된 이 PC는 바로 사용 가능합니다.
소요 시간
패키지 설치 10분 + Ollama 모델 다운로드 30분~1시간 (인터넷 속도에 따라 다름)
STEP 01
프로젝트 폴더 만들기
파일 탐색기에서 C:\SeikProject\meeting 폴더를 생성합니다. 경로에 한글·공백 없이 만드세요.
STEP 02
파일 5개 배치
meeting.py · config.json · prompt.md · glossary.md · 회의록만들기.bat 을 폴더에 저장합니다.
STEP 03
Python 가상환경 & 패키지 설치
폴더에서 PowerShell을 열고 아래 명령어를 실행합니다.
PowerShell
# 가상환경 생성
python -m venv .venv

# 패키지 설치 (5~10분)
.\.venv\Scripts\python.exe -m pip install faster-whisper nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
STEP 04
Ollama 모델 설치
Ollama 앱 실행 후 cmd에서 입력합니다. gemma4:12b는 약 8GB 다운로드됩니다.
명령 프롬프트
# 고품질 모델 (기본, ~8GB)
ollama pull gemma4:12b

# 빠른 모델 (선택, ~3GB)
ollama pull gemma3:latest
⚠️
Ollama 버전 주의
gemma4:12b는 0.30.6 이상에서만 동작합니다. 오류 시 winget upgrade --id Ollama.Ollama
STEP 05
config.json — Vault 경로 설정
메모장으로 config.json을 열어 vault_meeting_dir을 내 Obsidian 경로로 변경합니다.
config.json
"vault_meeting_dir": "C:\\저장소\\옵시디언\\회의록"  ← 이 경로만 변경
💡
역슬래시는 \\ 두 개
JSON에서 Windows 경로를 쓸 때는 C:\\Users\\이름\\Vault 처럼 두 번 씁니다.
python -m venv faster-whisper nvidia-cublas-cu12 ollama pull gemma4:12b

DAILY USE · 매일 사용
사용법
방법 1 ⭐ 추천
녹음 파일을 회의록\ 폴더에 복사하고 회의록만들기.bat 더블클릭하면 끝. 폴더 안 모든 파일 일괄 처리.
방법 2 드래그앤드롭
처리할 파일 1개를 마우스로 집어서 회의록만들기.bat 위에 끌어다 놓기.
방법 3 명령어
제목 지정, 모델 선택 등 옵션이 필요할 때만 PowerShell에서 직접 실행.
명령어 예시 (방법 3)
# 특정 파일 + 제목 지정
python meeting.py "파일.m4a" --title "주간 정기회의"

# 빠른 모델로 처리 (~3분)
python meeting.py "파일.m4a" --ollama-model gemma3:latest

# 고품질 모델로 처리 (~17분)
python meeting.py "파일.m4a" --ollama-model gemma4:12b

CONFIG · 설정 참조
config.json 상세 설명
편집 방법
메모장으로 config.json을 열어 원하는 값만 수정하고 저장합니다. 다음 실행부터 바로 적용됩니다.
핵심 메시지
"경로, 모델, 타임아웃 — 이 세 가지만 알면 모든 상황에 대응 가능합니다."
config.json — 현재 설정
{
  "vault_meeting_dir":  "C:\\저장소\\옵시디언\\회의록",
  "whisper_model":      "medium",
  "whisper_device":     "auto",
  "whisper_language":   "ko",
  "ollama_model":       "gemma4:12b",
  "ollama_num_ctx":     65536,
  "ollama_timeout":     5400,
  "save_raw_transcript":true
}
항목현재 값설명
vault_meeting_dir…\옵시디언\회의록완성된 회의록 .md가 저장될 Obsidian 폴더 경로
whisper_model"medium"small(빠름) · medium(기본) · large-v3(최고 정확도, ~3GB)
whisper_device"auto"auto: GPU 있으면 자동 사용 / cpu: 강제 CPU
ollama_model"gemma4:12b"빠른 처리 원하면 gemma3:latest로 변경
ollama_num_ctx65536한 번에 처리할 최대 토큰. 1시간 이상 회의면 131072로
ollama_timeout5400 (90분)AI 요약 최대 대기 시간(초). 긴 회의나 느린 PC는 늘리세요
save_raw_transcripttrue전사 원문을 txt로 별도 저장. false로 바꾸면 저장 안 함
vault_meeting_dir whisper_model ollama_num_ctx ollama_timeout

MODEL SELECT · 모델 선택
STT · LLM 모델 비교
STT 모델 (Whisper)
음성을 텍스트로 변환합니다. GPU에서 실행되어 35분 녹음 기준 약 2분 소요됩니다.
LLM 모델 (Ollama)
텍스트를 요약합니다. 4GB VRAM에서는 CPU로 실행되어 품질 vs 속도 트레이드오프가 있습니다.

🗣️ Whisper STT 모델 비교

모델크기속도정확도추천 상황
small~500MB매우 빠름보통짧은 회의, 빠른 처리 우선
medium ⭐~1.5GB빠름좋음현재 설정 — 대부분의 경우 최적
large-v3~3GB보통최고긴 회의, 잡음 많은 환경

🛠️
TROUBLESHOOT · 문제 해결
자주 묻는 질문
🔴 "Ollama 호출 실패" 오류가 나요

Ollama 앱이 실행 중이지 않을 때 발생합니다.

ollama serve  # 또는 시작 메뉴에서 Ollama 앱 실행

트레이(시계 오른쪽)에 Ollama 아이콘이 보이면 정상입니다.

🔴 GPU 오류 — "cublas64_12.dll not found"

meeting.py가 자동 처리하도록 설계되어 있습니다. 실패 시 CPU로 자동 전환됩니다(약 3~4배 느림). 강제 CPU 사용은 config.json에서 "whisper_device": "cpu"로 변경하세요.

🔴 회의록 내용이 중간에 잘려요

녹음이 1시간 이상이거나 num_ctx가 너무 작을 때 발생합니다.

"ollama_num_ctx": 131072  # 65536에서 두 배로
🔴 요약이 시간 초과(timeout)로 실패해요 
"ollama_timeout": 7200  # 2시간으로 설정
🟡 회의록에 오인식 단어가 계속 나와요

glossary.md에 항목을 추가하세요.

- `오인식된표현` → **올바른표현**
🟡 gemma4:12b pull 시 "requires a newer version" 오류 
winget upgrade --id Ollama.Ollama
🟡 처리 완료됐는데 Obsidian에서 파일이 안 보여요

1. config.json의 vault_meeting_dir 경로 확인
2. Obsidian에서 Ctrl+R로 새로고침

💡 처리 속도를 더 빠르게 하고 싶어요

1. LLM 모델 변경: gemma4:12b(~17분) → gemma3:latest(~3분)
2. Whisper 모델: medium → small(정확도 약간 낮아짐)
3. VRAM 12GB 이상이면 LLM도 GPU에서 3~5분 내 처리

파이프라인을 구축했다면,
녹음을 넣고 바로 시작하세요.

설치가 완료되었다면 회의록만들기.bat을 더블클릭해서 첫 번째 회의록을 만들어보세요.
