Claude Design란?
왜 주목받는가
클로드 디자인 출시 후 피그마 주가 83% 하락. 단순 일반인용이 아닌 현직 디자이너들의 피그마 의존도를 직격한 서비스로 평가.
만든 사람은?
클로드 디자인 담당 디자이너 Jenny — 전직 Figma 출신. 하루 일과: 코딩 50% · 피그마 30% · 커뮤니케이션 20%.

"프로 디자이너 입장에서 가장 성능이 좋은 모델. 클로드가 하네스(Harness)의 중요성을 가장 잘 이해하고 있는 회사다."

디자인 시스템 세팅
왜 먼저 해야 하나
디자인 시스템은 디자이너의 하네스(Harness)다. 폰트·컬러·버튼이 사전 세팅되면 일관되고 퀄리티 높은 디자인이 자동으로 나온다.
핵심 메시지
"디자인 시스템 = 디자이너의 하네스. 레고 조립하듯 미리 세팅하면 퀄리티가 달라진다."
추천 디자인 시스템
🍎
Apple iOS Design System
Figma Community · 인기 1위
전 세계에서 가장 많이 쓰는 디자인 시스템. iOS/iPadOS 앱 디자인에 최적.
글로벌 표준
🎨
Google Material 3
구글 공식 디자인 시스템
구글 생태계 앱 디자인 기준. Android 앱 및 바이브코딩 시 구글 가이드라인 준수에 필수.
안드로이드 표준
🇰🇷
원티드 디자인 시스템
Figma Community · 한국 특화
한국 정서에 맞게 커스터마이징된 오픈소스 시스템. Pretendard 폰트 기반. 한국 유저 최추천.
한국어 최추천
설치 방법 (Step by Step)
1
Figma Community에서 다운로드
figma.com → 좌측 커뮤니티 탭 → Design Resources → UI Kits → 원하는 시스템 선택 → Open in Figma → Make a copy
2
로컬 파일로 저장
Figma 상단 메뉴 → File → Save local copy → .fig 파일 다운로드 완료
3
Claude Design에 업로드
claude.ai → 사이드바 디자인 탭 → Design System → Create New → Upload Figma File → 다운로드한 .fig 파일 선택
4
AI 분석 대기 (약 5분)
"It will take about 5 minutes" 메시지 후 AI가 파일 전체 해석. 컬러·폰트·컴포넌트 자동 추출.
5
Publish 버튼 클릭
Review Draft → 확인 후 Publish 클릭. 이후 새 디자인 생성 시 이 시스템이 자동 적용됨.
💡
Pretendard 폰트 설정
원티드 디자인 시스템 사용 시 Pretendard 폰트가 필요합니다. 구글에서 "pretendard" 검색 → 눈누(noonnu.cc) → 글꼴 다운로드 → Claude Design에 업로드.

18:44 ~ 22:29 · PRD → 디자인
PRD부터 프로토타입까지
PRD란?
Product Requirements Document. AI가 읽을 수 있는 최소한의 요구사항 기획서. 이걸 먼저 만들면 훨씬 구체적인 디자인이 나온다.
이 영상의 실습 예제
카카오T 시니어 — 시니어(노인)와 자녀가 함께 쓰는 택시 앱 PRD 작성 후 원티드 디자인 시스템으로 구현.
STEP 1 — Claude에서 PRD 생성
claude.ai 입력 프롬프트
시니어들이 이용할 수 있는 택시 앱의 PRD를 만들어 주세요
📋
생성되는 PRD 구성
목적 요약 → 배경 및 시장 분석 → 문제 정의 → 타겟 페르소나 → 핵심 기능 요구사항 → 성공 지표
STEP 2 — PRD를 Claude Design에 붙여넣기
Claude Design 입력 프롬프트 (원티드 디자인 시스템 선택 후)
첨부한 PRD 기반으로 프로토타입을 만들어 줘.
PRD를 통해서 가설을 직접 내가 세 개를 뽑아 보고
각 가설에 해당하는 플로우를 화면 다섯 개 이상 뽑아 줘.
팀과 같이 논의하고 싶어.
생성된 3가지 시나리오 (실습 결과)
A안 · 음성 AI
음성으로 택시를 호출하는 AI 플로우. "오늘도 서울대병원 가세요?" 형태의 맥락 인식. 노란색 계열 디자인.
B안 · 단순 대형 UI
시니어에게 적합한 크고 단순한 버튼 위주 화면. AI가 목적지를 제안하고, 사용자는 크게 표시된 선택지만 누르면 됨.
C안 · 자녀 연동 (채택)
시니어 화면 + 자녀 화면 실시간 싱크. 탑승 여부 트래킹, 도착 시 자녀에게 자동 알림. 가장 완성도 높은 시나리오.
✏️
에디트 모드 활용
생성된 화면 요소를 탭하면 텍스트 수정, 색상 변경, 위치 조정이 가능합니다. 다만 Figma 수준의 자유도는 아직 제한적.
PRD 가설 3개 플로우 5화면 이상 에디트 모드 팀 논의용

인터랙티브 프로토타입 & Claude Code 연동
정적 → 인터랙티브
시안 화면을 "클릭 가능한 움직이는 화면"으로 전환. 실제 사용자 테스트와 팀 프레젠테이션에 바로 활용 가능.
Claude Code 연동
Share → Handoff to Claude Code로 프로토타입 전체를 코드로 변환. 실제 배포 가능한 앱으로 이어짐.
인터랙티브 프로토타입 생성 방법
Claude Design 추가 프롬프트
시안을 기반으로 해서 인터랙티브 프로토타입을 만들어 보자
Claude Code 연동 절차
1
Share 버튼 클릭
Claude Design 우상단 Share → 여러 내보내기 옵션 표시
2
Handoff to Claude Code 선택
자동으로 프롬프트 생성됨: "Fetch design file" — 이 웹사이트 내용을 Claude Code로 옮기는 명령어.
3
Copy Command → Claude Code에 붙여넣기
Claude Code 터미널에 붙여넣기하면 디자인 파일을 불러와 수정 가능한 상태로 변환.
⚠️
토큰 소모 주의
Claude Design은 크레딧 소모량이 매우 큽니다. Pro 계정 기준 디자인 시스템 하나 만들면 추가 화면 생성이 어려울 수 있음. 디자인 시스템을 .md 파일로 다운로드해 Claude Code에서 재사용하는 방식 권장.
💡
디자인 시스템 재활용 꿀팁
Share → Download Project File로 디자인 시스템 파일 저장 → design.md로 변환해 Claude Code 컨텍스트에 항상 포함. 이렇게 하면 Claude Design 없이도 동일한 디자인 시스템으로 코딩 가능.
인터랙티브 프로토타입 Handoff to Claude Code design.md Download Project File 토큰 소모 주의

핵심 팁 정리
Claude Design 품질 평가 (프로 디자이너 시각)
현재 수준
"주니어 디자이너가 보조 화면을 만들어 준 수준" — Gemini나 Claude Code보다 훨씬 높은 디자인 품질을 보여줌.
강점 영역
앱 디자인, 웹사이트 UI에서 압도적 성능. 그리드·레이아웃 정렬, 버튼 요소 일관성이 특히 뛰어남.
한계
시니어(10년차+) 디자이너 수준은 아직 아님. 아이콘 보완 필요. 편집 범위 제한적. 토큰 소모 큼.
디자이너의 미래 역할
단순 화면 제작보다 플로우·가설 검증·사용자 테스트 업무에 집중하게 될 것.
99%가 놓치는 핵심: 시스템 세팅이 먼저다

"클로드 디자인에서 가장 좋은 결과를 내려면 디자인 시스템 세팅부터 시작하라. 시스템 없이 바로 만들면 퀄리티가 절반이다."

한눈에 보기 — 전체 워크플로우
STEP 01
Figma Community → 디자인 시스템 다운로드

Claude에서 PRD 작성
"[서비스명] PRD 만들어 줘" → 생성된 문서 복사
STEP 04
Claude Design → New Prototype 생성
