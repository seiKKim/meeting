STEP 00 · 먼저 설치
Ollama 설치 (처음 한 번만)

Ollama는 AI 모델을 내 PC에서 돌릴 수 있게 해주는 무료 프로그램입니다. 이미 설치되어 있다면 건너뛰세요.

  • 1

    Ollama 설치 파일 다운로드

    아래 사이트에서 Windows용 설치 파일을 받아 실행합니다.

    # 브라우저에서 접속 https://ollama.com/download/windows
  • 2

    설치 확인

    설치 후 PowerShell 또는 명령 프롬프트(cmd)를 열고 아래를 입력합니다.

    ollama --version

    ollama version X.X.X 처럼 버전이 나오면 성공입니다.

  • 3

    Gemma 4 2B 모델 다운로드 (~2GB)

    아래 명령어를 입력하면 로컬 AI 모델이 다운로드됩니다. Wi-Fi 환경에서 약 5~10분 소요됩니다.

    ollama pull gemma4:e2b-it-q4_K_M
    ⚠️
    JSON 오류가 자주 발생하는 경우
    Gemma 4 2B 대신 더 안정적인 Qwen 2.5 Coder 7B 모델을 사용하세요. 크기는 크지만 오류가 거의 없습니다.

    ollama pull qwen2.5-coder:7b
  • 1

    Homebrew로 설치 (권장)

    Homebrew가 없다면 먼저 brew.sh에서 설치하세요. 그 후 터미널에서:

    brew install ollama

    또는 ollama.com/download/mac에서 macOS 앱으로 설치할 수도 있습니다.

  • 2

    Ollama 서비스 시작

    ollama serve

    이 창은 열어둔 채로 새 탭을 열어 다음 단계를 진행하세요.

  • 3

    Gemma 4 2B 모델 다운로드 (~2GB)

    ollama pull gemma4:e2b-it-q4_K_M
    ⚠️
    JSON 오류가 자주 발생하는 경우
    더 안정적인 모델로 교체하세요.

    ollama pull qwen2.5-coder:7b

    # PowerShell에서 실행 mkdir "$env:USERPROFILE\.codex\skills" -Force xcopy /E /I token-router "$env:USERPROFILE\.codex\skills\token-router"

    등록 후 Codex 대화에서 $token-router로 호출합니다.

STEP 03 · 실전 사용
3가지 사용 시나리오

시나리오 1 — 에러 로그 분석 (error_log)

배포 로그나 에러 로그가 수천 줄일 때 사용합니다. "payment timeout" 같은 특정 에러를 검색하면 관련 줄만 뽑아냅니다.

# 기본 사용 set OLLAMA_NUM_CTX=4096 set OLLAMA_KEEP_ALIVE=0s python scripts/router.py error_log deploy.log --query "database migration timeout" # 다른 모델 사용 시 set OLLAMA_MODEL=qwen2.5-coder:7b python scripts/router.py error_log deploy.log --query "payment failed"
# 기본 사용 OLLAMA_NUM_CTX=4096 OLLAMA_KEEP_ALIVE=0s \ python3 scripts/router.py error_log deploy.log --query "database migration timeout" # 다른 모델 사용 시 OLLAMA_MODEL=qwen2.5-coder:7b \ python3 scripts/router.py error_log deploy.log --query "payment failed"

시나리오 2 — 긴 소스코드 분석 (heavy_code)

수백~수천 줄의 소스 파일에서 특정 기능·버그를 찾을 때 사용합니다.

set OLLAMA_NUM_CTX=4096 set OLLAMA_KEEP_ALIVE=0s python scripts/router.py heavy_code src/service.py --query "token expiration logic"
OLLAMA_NUM_CTX=4096 OLLAMA_KEEP_ALIVE=0s \ python3 scripts/router.py heavy_code src/service.py --query "token expiration logic"

시나리오 3 — 에이전트 지침 문서 라우팅 (agent_context)

CLAUDE.md, AGENTS.md, .cursorrules 같은 긴 지침 파일에서 현재 작업과 관련된 규칙만 추출합니다. 매 요청마다 전체 파일을 보내는 토큰 낭비를 막습니다.

set OLLAMA_NUM_CTX=4096 set OLLAMA_KEEP_ALIVE=0s python scripts/router.py agent_context docs/AGENTS.md --query "frontend testing workflow"
OLLAMA_NUM_CTX=4096 OLLAMA_KEEP_ALIVE=0s \ python3 scripts/router.py agent_context docs/AGENTS.md --query "frontend testing workflow"

  • !

    JSON 파싱 오류가 난다

    Gemma 4 2B가 JSON을 가끔 잘못 생성합니다. 더 안정적인 모델로 바꾸세요.

    ollama pull qwen2.5-coder:7b set OLLAMA_MODEL=qwen2.5-coder:7b python scripts/router.py error_log deploy.log --query "에러 내용"
    ollama pull qwen2.5-coder:7b OLLAMA_MODEL=qwen2.5-coder:7b \ python3 scripts/router.py error_log deploy.log --query "에러 내용"
  • !

    Ollama가 연결 안 된다

    Ollama 서비스가 실행 중인지 확인하세요.

    # Ollama 상태 확인 ollama list # 실행 안 되어 있으면 — 시스템 트레이에서 Ollama 아이콘 클릭 or ollama serve
    # 새 터미널 탭에서 ollama serve # 모델 목록 확인 ollama list
  • !

    python 명령어를 찾을 수 없다 (Windows)

    Python이 PATH에 등록되지 않은 경우입니다. 설치 시 "Add Python to PATH"를 체크했는지 확인하세요. 또는 py 명령어를 시도해보세요.

    # python 대신 py로 시도 py scripts/router.py error_log deploy.log --query "에러" # 또는 전체 경로로 실행 C:\Python312\python.exe scripts/router.py error_log deploy.log --query "에러"
